# SLCMA_Adv_SHAPESProject
Developmental timing of adversity on threat and safety learning in the brain and fear-related psychology symptoms

Included in this folder are the data utilized for the developmental timing project. Variables have been de-identified and only strictly necessary variables are accessible.

The R Notebook "DevTiming_SHAPES_GitHubScript.Rmd" contains all code used to run analyses on cumulative versus developmentally-specific effects of adversity on neural correlates of threat and safety learning, as well as fear-related psychopathology symptoms.
